# Анализ тональности русскоязычных сообщений и отзывов

Классификация коротких русскоязычных текстов (посты в соцсетях, комментарии, отзывы) по тональности.

## Задача

На вход подаётся текст на русском языке, на выходе — метка тональности и вероятности классов.

| Вход | Выход |
|---|---|
| строка UTF-8 или CSV (`id`, `text`) | `positive` / `negative` / `neutral` / `speech` / `skip` + вероятности |

Где пригодится: мониторинг отзывов и репутации бренда, приоритизация обращений в поддержку, модерация, исследования общественного мнения.

## Данные

**RuSentiment** ([Rogers et al., 2018](https://aclanthology.org/C18-1064/)): 31 185 постов ВКонтакте, 5 классов, официальная тестовая выборка из 2 967 постов.

Сами данные в репозитории не хранятся: инструкция по загрузке лежит в `data/README.md`.

## Подходы

1. **Бейзлайн:** TF-IDF + логистическая регрессия.
2. **Основная модель:** дообучение RuBERT (и компактной модели для быстрого инференса).
3. **Дополнительно:** сравнение с zero-shot LLM.

## Метрики

- **Macro-F1**: основная метрика, потому что классы несбалансированы.
- **Weighted F1**: для сравнения с опубликованными результатами.
- Accuracy, P/R/F1 по классам, матрица ошибок.
- Время инференса и размер модели.
